# FitCoach iOS

SwiftUI, iOS 17+, no third-party packages. The Xcode project is generated by XcodeGen.

## Run

```sh
brew install xcodegen
cd ios
xcodegen            # creates FitCoach.xcodeproj (and FitCoach/Info.plist)
open FitCoach.xcodeproj
```

Pick an iPhone simulator and press Run. Start the backend first (`../backend`, port 8000).

- **Simulator:** `http://localhost:8000` (the default in `FitCoach/Config.swift`) works as is.
- **Real device:** set `Config.baseURL` to your Mac's LAN IP (`ipconfig getifaddr en0`, e.g. `http://192.168.1.20:8000`)
  or an ngrok URL, run uvicorn with `--host 0.0.0.0`, and pick your team under Signing & Capabilities.
- **No backend yet:** set `Config.useMock = true`. `MockAPIClient` serves the SPEC §2.4 seed data as JSON
  through the real decoders. Mutations don't persist in mock mode.

## Layout

```
FitCoach/
  App.swift              app entry, tab bar, AppStore (@Observable state + all API calls)
  Config.swift           base URL, mock flag
  Theme.swift            colors, fonts, number formatting
  API/                   APIClient (actor), Models (SPEC §2.2 shapes), MockAPIClient
  Views/                 Today, Coach, Train (+ WorkoutDetailView), Eat, Goals, Onboarding
  Views/Components/      Ring, Bar, MacroBar, chips, button styles
```

Cross-tab navigation goes through `AppStore.selectedTab`. `coachDraft` prefills the Coach input,
and `trainPath` opens a workout in the Train tab.
