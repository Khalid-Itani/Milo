# Milo iOS

SwiftUI, iOS 17+. The only package is the Visualize SDK (body scans), declared in `project.yml`.
The Xcode project is generated by XcodeGen; folder and target names are still `FitCoach`.

## Run

```sh
brew install xcodegen
cd ios
xcodegen            # creates FitCoach.xcodeproj (and FitCoach/Info.plist)
open FitCoach.xcodeproj
```

Create `FitCoach/Secrets.swift` first (see Backend auth below), start the backend (`../backend`, port 8000),
pick an iPhone simulator and press Run.

- **Simulator:** uses `http://localhost:8000` (`Config.swift`, simulator branch).
- **Real iPhone:** uses the `#else` URL in `Config.swift`. Many Wi-Fi networks block phone-to-Mac traffic, so
  expose the backend with `cloudflared tunnel --url http://localhost:8000` and paste the printed
  `https://….trycloudflare.com` URL there. The URL changes every time the tunnel restarts, so rebuild then.
- **Signing:** team and bundle ID (`com.agxmbhir.fitcoach`) live in `project.yml`; change `DEVELOPMENT_TEAM`
  to your own team. Free Apple IDs expire installs after 7 days.
- **Body scans:** need a Face ID iPhone and the team + bundle ID registered in the Visualize portal.
  The publishable key is `VZPublishableKey` in `project.yml`.
- **No backend yet:** set `Config.useMock = true`. `MockAPIClient` serves the SPEC §2.4 seed data as JSON
  through the real decoders. Mutations don't persist in mock mode.

The app is light-mode only (`UIUserInterfaceStyle: Light`).

## Layout

```
FitCoach/
  App.swift              app entry, tab bar, AppStore (@Observable state + all API calls)
  Config.swift           base URL, mock flag
  Theme.swift            colors, fonts, number formatting
  API/                   APIClient (actor), Models (SPEC §2.2 shapes), MockAPIClient
  Views/                 Today, Coach, Train (+ WorkoutDetailView), Eat, Goals, Onboarding,
                         BodyScanView (Visualize scan card + scan history)
  Assets.xcassets/       app icon
  Views/Components/      Ring, Bar, MacroBar, chips, button styles
```

Cross-tab navigation goes through `AppStore.selectedTab`. `coachDraft` prefills the Coach input,
and `trainPath` opens a workout in the Train tab.

## Backend auth (required)

The backend needs a demo bearer token. Create `FitCoach/Secrets.swift` (gitignored) with the same value as `DEMO_API_TOKEN` in `backend/.env`:

```swift
enum Secrets {
    static let demoAPIToken = "<DEMO_API_TOKEN>"
}
```
